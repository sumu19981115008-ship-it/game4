### 2. 战斗动画精灵表（Pokémon Showdown GIF 拆帧）

来源：`https://play.pokemonshowdown.com/sprites/ani/{英文名}.gif`  
注意：需要浏览器 User-Agent，Python urllib 会 403，改用 curl 子进程调用

| 工具脚本 | 功能 |
|---------|------|
| `tools/gif_to_spritesheet.py` | 下载 GIF → 逐帧合并为精灵表 PNG + meta.json |
| `tools/gen_sprite_frames.py` | 读取 meta.json → 生成 Godot SpriteFrames .tres |

处理结果：19只 × 3变体（front/back/shiny）= **57套动画资源**  
存放路径：`assets/sprites/animated/{front|back|shiny}/{编号}_sheet.png`

SpriteFrames 动画名规范：`battle_front` / `battle_back` / `battle_shiny`

---

### 3. PokemonDatabase 新增接口

```gdscript
# 静态精灵图
PokemonDatabase.get_sprite_path(id, back, shiny) -> String
PokemonDatabase.get_sprite_texture(id, back, shiny) -> Texture2D

# 动画精灵表
PokemonDatabase.get_anim_frames_path(id, back, shiny) -> String
PokemonDatabase.get_anim_frames(id, back, shiny) -> SpriteFrames
```

两组接口均含本地文件存在判断 + 回退到正面普通图的逻辑。

### 🐛 玩家行走动画帧错位（优先级：高）

**现象**：WASD 移动时人物像在旋转，尤其朝下走时夹杂侧身帧  
**根因**：原图9帧中帧2和帧5是侧面帧，不属于 DOWN/UP 方向  
**当前状态**：已修正 DOWN 用帧0/1/3，但视觉上仍有旋转感，需要再次逐帧核验  
**下次任务**：用分格预览图逐帧确认每帧实际朝向，重新正确映射帧索引

原图帧布局（初步分析，待确认）：
