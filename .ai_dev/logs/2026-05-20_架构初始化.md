# 开发日志 - 2026-05-20

## 本次完成内容

架构初始化，建立完整项目骨架。

### 创建的文件

**project.godot**
- 基准分辨率 1280×720，canvas_items 拉伸
- 像素渲染：nearest filter + 像素对齐
- 碰撞层：player/npc/wall/trigger/wild_zone/item/projectile/camera_zone
- 输入映射：WASD移动、Shift跑步、Z确认、X取消、F交互、ESC菜单、B背包、M地图
- Autoload 12个单例按依赖顺序注册

**数据层（data/）**
- PokemonEnums.gd：所有枚举（属性/状态/成长/蛋组/技能分类/战斗结果/朝向）
- PokemonSpeciesData.gd：种族数据 Resource
- LearnableMove.gd / EvolutionCondition.gd：关联数据
- MoveData.gd：技能数据 Resource
- NatureTable.gd：25种性格修正表

**逻辑层（scripts/）**
- PokemonInstance.gd：个体数据 + 能力值计算公式（官方HP公式/普通公式/性格修正）
- Player.gd：8方向移动 + 加速摩擦 + 动画接口 + 信号
- PlayerCamera.gd：平滑跟随 + 边界 + 锁定解锁
- ZoneTransition.gd：三种区域切换（无缝/淡入淡出/加载）
- StoryTrigger.gd：剧情触发器（单次/多次，Flag条件）
- BattleStateMachine.gd：回合制8阶段状态机
- BattleCalculator.gd：官方伤害公式 + 急所 + 命中判定
- TypeChart.gd：完整18×18属性相克表
- CaptureSystem.gd：第六世代捕捉公式
- MegaEvolutionSystem.gd：超级进化系统
- CollisionLayers.gd：碰撞层常量
- NetworkManager.gd：联机预留框架
