## 关键 Bug 修复过程

### Bug 1：tiles.png 在 Godot 显示灰白
- 原因：tiles.png 是 mode=P（调色板索引图），Godot 不认
- 修复：`tools/bake_tileset_palettes.py` 将 .pal 烘焙进 RGBA PNG（tiles_rgba.png，2× 放大）

### Bug 2：颜色解析错误（convert("L") 陷阱）
- 原因：`img.convert("L")` 会把调色板颜色0（白色）映射为亮度255，导致 local_idx=255%16=15，透明变不透明
- 修复：`np.array(mode=P image)` 直接获得调色板索引矩阵，不做颜色转换

### Bug 3：Secondary tileset tile index 偏移缺失
- 原因：GBA secondary tileset 从全局 tile index 512 开始，metatile entry 里 tile_raw=514 要查 pet_raw[514-512=2]
- 修复：`if is_secondary and tile_raw >= 512: arr, tidx = pet_raw, tile_raw - 512`

### Bug 4：房屋粉紫色轮廓
- 原因：默认 combined，slot10 → pet[4]，pet[4] 含 (255,0,255) 品红占位色
- 修复：HOUSE_METAS 用 slot10 → pet[1]（橙棕）

### Bug 5：研究所颜色错误（黄绿色）
- 原因：slot8 → pet[2]（绿草地），slot14 → pet[8]（黄绿），两者都不对
- 修复：LAB_BODY_METAS 用 slot8 → pet[3]（灰/砖红），slot14 → pet[3]
- 顶行另处理：LAB_TOP_METAS 用 slot8 → pet[9]（橙色暖调）

### Bug 6：研究所顶行显示灰白（不是橙色）
- 原因：顶行 meta[524-526,578,579] 用 slot2（底）+ slot8（顶），统一 override slot8→pet[3] 导致顶行也变灰
- 修复：拆分 LAB_TOP_METAS vs LAB_BODY_METAS，各自用不同 combined

### Bug 7：品红色透明导致黑色背景漏出
- 原因：pet[3] local_idx=6/7 是 (255,0,255) 占位色，底层透明后显示黑色背景
- 修复：底层（is_bottom=True）品红色用相邻 index 颜色替代；顶层品红保持透明

### Bug 8：超出范围的 tile（pet_idx 288-307）
- 原因：petalburg tiles.png 只有 160 个图块，meta[586,587] 底层引用 pet[288-307]
- 修复：超出范围时用 `_safe_color(combined, pal_slot, 1)` 纯色填充（index 1 = slot 首色）
