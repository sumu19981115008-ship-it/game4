# 美术资源管理策划案

## 1. 精灵图素材来源

### 开源库：PokeAPI Sprites
- **仓库地址**：https://github.com/PokeAPI/sprites
- **协议**：MIT 开源，可免费用于同人游戏
- **内容**：全9世代所有宝可梦精灵图，含正面/背面/闪光/各世代像素版本
- **仓库大小**：约 1.6GB

### 战斗动画 GIF：Pokémon Showdown
- **来源**：https://play.pokemonshowdown.com/sprites/
- **内容**：宝可梦战斗动态 GIF（正面/背面/色违）
- **协议**：开源，学习用途可用

---

## 2. 访问方式：jsDelivr CDN 加速

直接引用 PokeAPI GitHub 仓库内容，通过 jsDelivr CDN 代理访问，无需下载也无需自己的云存储。

### URL 规则

```
# 静态精灵图（正面）
https://cdn.jsdelivr.net/gh/PokeAPI/sprites@master/sprites/pokemon/{编号}.png

# 静态精灵图（背面）
https://cdn.jsdelivr.net/gh/PokeAPI/sprites@master/sprites/pokemon/back/{编号}.png

# 闪光版本（色违）
https://cdn.jsdelivr.net/gh/PokeAPI/sprites@master/sprites/pokemon/shiny/{编号}.png

# 闪光背面
https://cdn.jsdelivr.net/gh/PokeAPI/sprites@master/sprites/pokemon/back/shiny/{编号}.png

# 战斗动画 GIF（正面）
https://play.pokemonshowdown.com/sprites/ani/{英文名}.gif

# 战斗动画 GIF（背面）
https://play.pokemonshowdown.com/sprites/ani-back/{英文名}.gif

# 战斗动画 GIF（色违）
https://play.pokemonshowdown.com/sprites/ani-shiny/{英文名}.gif
```

### 示例（皮卡丘 #25）

```
正面静态：https://cdn.jsdelivr.net/gh/PokeAPI/sprites@master/sprites/pokemon/25.png
背面静态：https://cdn.jsdelivr.net/gh/PokeAPI/sprites@master/sprites/pokemon/back/25.png
正面动画：https://play.pokemonshowdown.com/sprites/ani/pikachu.gif
背面动画：https://play.pokemonshowdown.com/sprites/ani-back/pikachu.gif
```

### 本地化方案（发布前执行）

发布游戏前需将所有用到的精灵图下载到本地，存放路径规划：

```
d:/fixelflow/game4/assets/sprites/
├── pokemon/
│   ├── front/         # 正面静态 PNG
│   ├── back/          # 背面静态 PNG
│   ├── front_shiny/   # 闪光正面
│   └── back_shiny/    # 闪光背面
└── animated/
    ├── front/         # 正面 GIF
    ├── back/          # 背面 GIF
    └── shiny/         # 闪光 GIF
```

下载脚本示例（按编号批量下载）：

```bash
# 下载指定宝可梦精灵图（以皮卡丘#25为例）
curl -L "https://cdn.jsdelivr.net/gh/PokeAPI/sprites@master/sprites/pokemon/25.png" \
     -o assets/sprites/pokemon/front/25.png
```

## 4. Godot 4 中的使用方式

### 开发阶段（在线引用）

```gdscript
# 动态加载在线精灵图
func load_pokemon_sprite(pokemon_id: int) -> Texture2D:
    var url = "https://cdn.jsdelivr.net/gh/PokeAPI/sprites@master/sprites/pokemon/%d.png" % pokemon_id
    var http = HTTPRequest.new()
    add_child(http)
    http.request(url)
    # 异步回调处理...
```

### 发布阶段（本地文件）

```gdscript
# 加载本地精灵图
func load_pokemon_sprite(pokemon_id: int) -> Texture2D:
    var path = "res://assets/sprites/pokemon/front/%d.png" % pokemon_id
    return load(path)
```

---

## 5. 注意事项

- jsDelivr 有 CDN 缓存，新上传到 PokeAPI 的素材可能有延迟
- 游戏发布时必须本地化，不能依赖外部 CDN
- Pokémon Showdown 的 GIF 动画英文名需全小写（如 `pikachu`、`charizard`）
- 部分宝可梦有特殊形态后缀（如 `charizard-mega-x`、`pikachu-alola`）
