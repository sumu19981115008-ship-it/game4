## 1. 整体视觉风格规范

### 1.1 设计哲学

本作采用**复古像素风格 + 现代简约 UI** 的混合设计语言，致敬经典宝可梦 GBA/DS 时代美学，同时保持界面清晰度与可读性。UI 整体风格参考 Pokémon Legends: Z-A 的 Art Nouveau（新艺术主义）装饰线条，融入手绘描边与金属光泽质感。

### 1.3 字体规范

| 字体层级 | 字体名称 | 字号 | 行高 | 用途 |
|----------|----------|------|------|------|
| 标题 H1 | `PixelMplus12`（像素字体） | 24px | 1.2 | 界面大标题 |
| 标题 H2 | `PixelMplus12` | 18px | 1.3 | 面板标题、宝可梦名称 |
| 正文 | `PixelMplus10` | 14px | 1.4 | 道具描述、对话文字 |
| 小字 | `PixelMplus10` | 10px | 1.5 | 数值标签、快捷键提示 |
| 数字专用 | `m5x7`（等宽像素字体） | 16px | 1.0 | HP 数值、等级显示 |
| 日文回退 | `DotGothic16` | 同上 | 同上 | 日文字符备用 |

**字体加载方式（Godot 4）**：
- 将字体文件放入 `res://assets/fonts/`
- 在 `Theme` 资源中统一注册，避免各节点单独引用
- 中文支持需导入完整字符集 `.ttf`，并在 `DynamicFontData` 中启用 `antialiased = false` 以保持像素风格

### 1.4 像素风格标准

| 规范项 | 标准值 | 说明 |
|--------|--------|------|
| 基础渲染分辨率 | 320×180 | 逻辑像素，最终输出 1920×1080（×6 整数倍） |
| UI 渲染分辨率 | 640×360 | UI 层独立 SubViewport，×3 倍输出 |
| 图标网格单元 | 16×16 px | 所有图标基础尺寸 |
| 宝可梦精灵 | 64×64 px | 正面站立图，战斗中 80×80 px |
| 按钮最小尺寸 | 64×16 px（逻辑像素） | 防止过小点击区域 |
| 像素描边宽度 | 1px | 所有 UI 元素外描边统一 1px |
| 圆角半径 | 0px | 像素风格不使用圆角，改用直角+斜切角装饰 |

**Godot 4 像素渲染设置**：
```
项目设置 → Rendering → Textures → Default Texture Filter = Nearest
项目设置 → Display → Window → Stretch → Mode = canvas_items
项目设置 → Display → Window → Stretch → Aspect = keep
```

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│         [背景动画层：卢米奥斯城全景 + 粒子光效]              │
```

### 2.2 布局设计细节

- **标题区**：居于屏幕上方 30% 处，标题 Logo 为像素艺术图像（非文字），下方小字显示副标题
- **按钮区**：垂直居中对齐，按钮间距 8px，宽度统一 160px，高度 28px
- **底栏**：版本号左下角，开发信息右下角，字号 10px 灰色
- **无存档时**："继续游戏"按钮置灰不可点击，Tooltip 显示"暂无存档"

### 2.3 按钮功能

| 按钮 | 功能 | 触发场景 |
|------|------|----------|
| 开始游戏 | 新建存档 → 进入角色创建流程 | 始终可用 |
| 继续游戏 | 加载最近一次存档 | 存档文件存在时 |
| 图鉴模式 | 进入独立宝可梦图鉴浏览界面 | 始终可用 |
| 设 置 | 打开设置弹窗（与游戏内设置共用） | 始终可用 |
| 退 出 | 弹出二次确认对话框后退出程序 | 始终可用 |

### 2.4 背景动画说明

**背景层（Layer -1）**：
- 卢米奥斯城像素全景图，分为前景/中景/远景三层
- 视差滚动：远景每帧移动 0.1px，中景 0.2px，前景 0.4px（向左缓慢平移）
- 城市剪影上方有霓虹灯闪烁动画（`AnimatedSprite2D`，帧率 4fps）

**粒子层（Layer 0）**：
- 金色光粒从下方飘起，`GPUParticles2D`，粒子数量 60，生命周期 3s
- 粒子颜色 `#F5C542`，大小 2×2px，透明度 `0.3 → 0.0` 渐出

**标题动画**：
- 游戏启动后，标题 Logo 从透明度 0 淡入（时长 1.2s），同步轻微向上位移 8px
- 按钮区逐条延迟显示，间隔 0.15s，每条从下方 12px 位移 + 淡入

### 2.5 交互逻辑

- 按钮悬停（鼠标/手柄游标）：背景色从 `#1C2B3A` 过渡到 `#2A3F55`，左侧出现 2px 金色指示条，播放轻微音效（tick_light.wav，音量 -12dB）
- 按钮按下：轻微向下位移 1px + 变暗，释放后弹回，播放 confirm.wav
- 手柄支持：默认焦点在"开始游戏"，上下键移动焦点，A 键确认

### 2.6 Godot 4 Control 节点实现思路

```
MainMenu (Control)
├── BackgroundLayer (SubViewportContainer)
│   ├── ParallaxBackground
│   │   ├── ParallaxLayer (远景)
│   │   ├── ParallaxLayer (中景)
│   │   └── ParallaxLayer (前景)
│   └── GPUParticles2D (金色粒子)
├── TitleLogo (TextureRect)          ← 像素艺术标题图
├── ButtonContainer (VBoxContainer)
│   ├── BtnNewGame (Button)
│   ├── BtnContinue (Button)
│   ├── BtnPokedex (Button)
│   ├── BtnSettings (Button)
│   └── BtnQuit (Button)
├── VersionLabel (Label)
└── CreditLabel (Label)
```

**脚本要点**：
- `MainMenu.gd` 在 `_ready()` 中检查存档文件 `user://save_data.json` 是否存在，设置 `BtnContinue.disabled`
- 使用 `Tween` 实现按钮入场动画，`set_parallel(true)` 批量执行
- 按钮主题通过全局 `Theme` 资源统一管理，不在节点内单独设置

### 2.7 注意事项

- 主菜单音乐在进入时淡入（0.8s），切换场景时淡出（0.5s），使用 `AudioStreamPlayer` + `Tween` 控制音量
- "退出"按钮需二次确认，防止误触（特别是手柄用户）
- 首次运行时"继续游戏"必须置灰，避免空存档读取崩溃

### 3.2 小地图

**位置**：右上角，可通过 Tab 键折叠/展开

**内容**：
- 玩家位置：中心白色圆点 `◉`（直径 3px）
- NPC/训练师：灰色小点（直径 2px）
- 兴趣点（道具、宝可梦出没区域）：金色 `★`（4×4px 图标）
- 区域边界：深灰色线框
- 地图底色：深蓝 `#0D1B2A`，探索过区域显示地形色调，未探索区域为纯黑

**交互**：
- 按 M 键切换全屏地图
- 滚轮缩放小地图（1× ~ 3×）
- 全屏地图可按区域筛选图标类型

### 3.3 血条/状态显示

**血条规格**：
- 宽 160px，高 10px（HUD 模式），圆角 0（像素风格）
- 三段颜色阈值：
  - `> 50%`：绿色渐变 `#27AE60 → #4CAF50`
  - `20% ~ 50%`：黄色渐变 `#F39C12 → #F5C542`
  - `< 20%`：红色渐变 `#C0392B → #E84040` + 闪烁动画（1Hz）
- 血条变化动画：目标值先到位（0.1s），背景"延迟条"追赶（0.6s，白色或橙色）

**状态异常图标**（16×16px，显示在血条下方）：

| 状态 | 图标颜色 | 缩写 | 闪烁 |
|------|----------|------|------|
| 中毒（PSN） | 毒紫 `#9B59B6` | PSN | 否 |
| 剧毒（TOX） | 深紫 `#6C3483` | TOX | 是（0.5Hz）|
| 麻痹（PAR） | 麻痹黄 `#F1C40F` | PAR | 是（2Hz）|
| 睡眠（SLP） | 冰蓝 `#74B9E8` | SLP | 否 |
| 冰冻（FRZ） | 冰白 `#AEE6E6` | FRZ | 否 |
| 灼伤（BRN） | 焦橙 `#E67E22` | BRN | 是（1Hz）|
| 混乱（CNF） | 粉紫 `#D7ACDE` | CNF | 是（3Hz）|

### 3.4 队伍快捷栏

**位置**：底部居中，距底边 8px

**布局**：6 个宝可梦头像槽，每槽 36×36px，间距 4px

| 状态 | 视觉表现 |
|------|----------|
| 当前出战 | 金色外框 2px + 轻微放大（×1.1） |
| 正常 | 银色外框 1px |
| 濒死（HP=0） | 灰度滤镜 + 红色叉号覆盖 |
| 状态异常 | 对应状态色点（右下角 6×6px 小圆点）|
| 空槽 | 深色虚线框 + 问号图标 |

**交互**：
- 按 1-6 数字键快速切换队伍宝可梦（战斗外）
- 鼠标悬停显示 Tooltip（名称、等级、HP 百分比）
- 战斗中，切换宝可梦触发"换场"流程，不可直接点击槽位

### 3.5 Rank 显示

**位置**：右下角，尺寸 60×60px

**内容**：
- 当前 Rank 等级（S/A/B/C/D）大字显示
- 下方星级图标（满星/半星/空星）
- 距离升级的进度条（细长条，宽 50px）

**Rank 颜色方案**：

| Rank | 主色 | 说明 |
|------|------|------|
| S | 金色 `#F5C542` | 最高级，带光晕动画 |
| A | 银色 `#BDC3C7` | 精英级 |
| B | 铜色 `#CD7F32` | 普通级 |
| C | 蓝色 `#3498DB` | 初级 |
| D | 灰色 `#7F8C8D` | 新手级 |

### 3.6 Godot 4 Control 节点实现思路

```
GameHUD (CanvasLayer, layer=10)
├── PlayerStatusPanel (PanelContainer) — 左上
│   ├── PokemonNameLabel (Label)
│   ├── LevelLabel (Label)
│   ├── HPBar (TextureProgressBar)
│   ├── HPValueLabel (Label)
│   └── StatusIconContainer (HBoxContainer)
│       └── StatusIcon (TextureRect) × N
├── MinimapPanel (PanelContainer) — 右上
│   ├── MinimapViewport (SubViewportContainer)
│   └── MinimapToggleBtn (Button)
├── PartyQuickBar (HBoxContainer) — 底部中
│   └── PokemonSlot (Control) × 6
│       ├── AvatarTexture (TextureRect)
│       ├── SelectFrame (NinePatchRect)
│       └── StatusDot (ColorRect)
└── RankDisplay (PanelContainer) — 右下
    ├── RankLabel (Label)
    ├── StarContainer (HBoxContainer)
    └── RankProgressBar (ProgressBar)
```

**脚本要点**：
- `HPBar.gd` 使用 `Tween` 实现双层血条动画（即时条 + 延迟追赶条）
- 状态图标使用 `AnimationPlayer` 控制闪烁，避免 `_process` 每帧计算
- `MinimapViewport` 使用独立 Camera2D，缩放比例 `0.1`，跟随玩家位置

### 3.7 注意事项

- HUD 所有元素在 `CanvasLayer(layer=10)` 中，确保始终在游戏画面上层
- 濒死闪烁效果不得影响性能，使用 `AnimationPlayer` 而非 `_process` 逐帧控制
- 手柄模式下 Tooltip 替换为按键提示（如 "▣ 查看状态"）
- 小地图在剧情过场时自动隐藏（监听 `GameStateManager.cutscene_started` 信号）

### 4.2 道具分类

| 分类 ID | 显示名称 | 图标颜色 | 包含道具类型 |
|---------|----------|----------|-------------|
| `all` | 全部 | 白色 | 所有道具 |

### 6.2 血条动画规范

**标准动画流程（以受伤为例）**：


**回血动画**（绿色粒子 + 血条正向增长）：
- 血条在 0.8s 内增长到目标值（Ease In Out）

## 8. 过渡动画规范

### 8.1 设计原则

- 所有过渡动画时长**不超过 0.8 秒**，避免影响游戏节奏
- 优先使用**淡入淡出 + 位移**组合，与像素风格保持一致
- 所有动画可在设置中调整速度（慢/普通/快/关闭）
- 关键交互反馈动画（按钮响应等）固定为最短时长，不受速度设置影响

### 8.2 场景切换动画

| 场景切换类型 | 动画方案 | 时长 | 实现方式 |
|-------------|----------|------|----------|
| 主菜单 → 游戏 | 全屏淡黑 → 淡入 | 进 0.5s + 出 0.8s | `ColorRect` alpha 动画 |
| 游戏 → 战斗 | 像素闪白 3次 + 淡入战斗场景 | 0.6s | 白色 `ColorRect` 闪烁 + 淡入 |
| 战斗 → 游戏 | 淡黑 → 游戏画面淡入 | 0.5s + 0.5s | 同上 |
| 区域切换（室内↔室外） | 竖向黑色滑入/滑出 | 0.4s + 0.4s | `ColorRect` Y 轴位移 |
| 传送点 | 白色扩散圆形遮罩 | 进 0.5s + 出 0.5s | `ShaderMaterial`（圆形遮罩 Shader）|
| 游戏 → 主菜单 | 全屏淡黑，音乐淡出 | 1.0s | `ColorRect` + `Tween` 音量 |

**实现示例（Godot 4 TransitionManager）**：
```gdscript
# 场景过渡管理器
func transition_to_battle():
    await flash_white(3, 0.15)   # 闪烁3次
    await fade_to_black(0.2)
    # 切换场景
    get_tree().change_scene_to_file("res://scenes/battle.tscn")
    await fade_from_black(0.4)
```

### 8.3 对话框弹出动画

| 对话框类型 | 进入动画 | 退出动画 | 时长 |
|-----------|----------|----------|------|
| 标准对话框（底部） | 从下方 20px 位移 + 淡入 | 向下 20px 淡出 | 0.2s |
| 系统弹窗（中央） | 从透明度 0 缩放至 1.05 → 1.0 | 缩小至 0.9 + 淡出 | 0.25s |
| Tooltip | 淡入（无位移） | 淡出 | 0.1s |
| 错误/警告弹窗 | 水平轻微抖动 3次 + 淡入 | 淡出 | 进 0.3s + 出 0.2s |
| 背包/状态界面 | 全屏淡入（带轻微模糊暗化背景） | 淡出 | 0.2s |

### 8.4 技能选择动画

```
步骤1: 玩家打开战斗菜单 → 命令面板从下方 8px 位移 + 淡入（0.15s）
```

### 8.8 Godot 4 全局过渡管理器实现思路

```gdscript
# res://autoload/TransitionManager.gd
extends CanvasLayer

@onready var overlay: ColorRect = $Overlay
@onready var anim_player: AnimationPlayer = $AnimationPlayer

func fade_to_black(duration: float) -> void:
    var tween = create_tween()
    tween.tween_property(overlay, "modulate:a", 1.0, duration)
    await tween.finished

func fade_from_black(duration: float) -> void:
    var tween = create_tween()
    tween.tween_property(overlay, "modulate:a", 0.0, duration)
    await tween.finished

func flash_white(count: int, interval: float) -> void:
    for i in range(count):
        overlay.modulate = Color.WHITE
        overlay.modulate.a = 0.9
        await get_tree().create_timer(interval / 2.0).timeout
        overlay.modulate.a = 0.0
        await get_tree().create_timer(interval / 2.0).timeout
```

**自动加载**：在项目设置 → AutoLoad 中注册 `TransitionManager`，全局可用

### 8.9 注意事项

- 所有 `await` 动画需在节点销毁前取消，防止悬空引用（使用 `tween.kill()` 在 `_exit_tree()` 中清理）
- 场景切换过渡期间禁止接受输入（通过 `get_viewport().gui_disable_input = true` 实现）
- 动画速度倍率由 `SettingsManager.get_setting("animation_speed")` 控制，过渡时长乘以该倍率
